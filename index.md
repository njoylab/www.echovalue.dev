# echoValue

## Summary

echoValue publishes pay-as-you-go APIs and free developer tools. The platform is aimed at developers who want simple HTTP-based services without subscriptions or unnecessary setup.

## Main Products

- DB API: hosted key-value storage for scripts, serverless apps, and agent state
- Mail2Webhook: receive inbound email as webhook deliveries
- Monitor API: upcoming monitoring service for web pages and remote files

## Shared Platform Model

- Pay-as-you-go credits
- No subscription
- Simple HTTP interfaces
- Documentation-first workflow
- Shared authentication and credit system across products
